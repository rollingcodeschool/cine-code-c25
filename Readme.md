# 🎬 Proyecto Cine Code

Practica de componentes de bootstrap sobre una web de un cine. Ofrece la cartelera de las ultimas peliculas, trailer de la pelicula a estrenar y candy del dine.

## 🦖 Demo del proyecto

Mira la demo [aqui](https://cine-code.netlify.app/)

## 🛠️ Tecnologias y herramientas usadas

- Html
- Css
- [Bootstrap v5.3](https://getbootstrap.com/) 

## ➡️ Pasos para clonar el repo

En una terminal ejecuta el siguiente comando

```bash
git clone https://github.com/rollingcodeschool/techConf
```
